## 🔥 OpenAI 公開內部遙測：每個研究員的工作日，背後掛著 3.1 個 agent 的工作日

OpenAI 在 9 月 6 日發布一份題為《Research acceleration: The view inside OpenAI》的說明，第一次公開自家研究機構用 coding agent 的量化數據，並把它框進「朝向等自動化的 AI 研究員（automated AI researcher）」的進度敘事裡。官方說法：今年初，研究員普遍只用少量 agent；到 8 月中，中位數研究員每天把 agent 融入工作，依 API 計價每天燒超過 600 美元推論，第 90 百分位的研究員每天用掉超過 7,000 美元的 token。總 agent 執行時間在 6 月前仍低於所有研究員的總工作時數，之後反轉——以標準 8 小時工時換算，8 月中起研究機構平均每投入 1 個人類工作日，就同時跑著約 **3.1 個 agent 工作日**。

其他數據照報：每位活躍實驗者跑的實驗數在 2026 年持續上升，8 月創下 2025 年 1 月開始追蹤以來新高——OpenAI 說這與 Codex 採用相關，但也明列自家可用的算力同樣大幅成長，兩者無法切割。委派給 agent 的任務性質也在變：從「研究與基礎設施程式碼」擴散到技術支援、監控執行等類別，但高階規劃仍只佔 agent 輸出 token 的極小比例。他們量測到研究員隸屬的除錯「office hours」參與度下降，其中一個團隊直接停止舉辦。成功率層面，用一個 agentic classifier 追蹤 1 到 7 月的任務成功與介入率，成功率普遍上升，但 OpenAI 自己註明：**超過一半的「成功」4–8 小時任務，過程裡都有 1 次以上人類介入**，任務越複雜、越需要人拉。

這份說明最硬的不是「3.1」這個數字，而是那張 pacing 的圖。官方說明：7/20 因為 agent 攻陷自家研究基礎設施的事故，暫停仍待部屬模型的強化學習訓練，Astra 級別的 RL 實驗在 7/20–8/6 間多為測試安全改動；8/7 出現 Astra 可能達 Critical 網安能力的初步證據後，模型被移進更高安全環境，之後一週 Astra 級別 GPU 配置下降 59.2%，但其他模型類別配置上升 17.2%，**約補回那 85% 的下降**——官方解釋這是算力被轉投到非 Astra 的工作負載。

「3.1 agent 工作日」要當成進度指標得先打個折。OpenAI 自己在一路都標註測量方法仍屬初步、工具改動太快、部分指標很容易湊但很難詮釋（「因為無人能確認它跟進度的關係」）。「agent-workday」數的是被燒掉的 token 與運算，不是產出的正確結果——而那份說明同時承認實驗數新高與算力成長不可分割。同樣是官方說法，OpenAI 宣稱已達成去年秋天喊出的「自動化研究實習生」（能承接「熟練研究者要做數天」的明確定義任務），並設定目標在 2028 年 3 月做出「自動化 AI 研究員」。用誰的尺量「加速」、由誰驗證，目前仍是 OpenAI 自己定義、自己公布；官方把「需要民主治理」「時機必須由知情公眾決定」寫進說明，但那份受治理的進度表，目前除了它的內部遙測沒有第二個來源。

## 第三方把 Astra 放上機械手臂：放積木碾壓，拼圖照樣卡在原地

Robocurve（一個做硬體 agent 評測的第三方專案）9 月 4 日在相同 YAM 機械手臂、同一套開放碼開源的 Inspect Robots agent policy 下，讓 GPT-6 Astra 跑跟先前 Fable 比測同樣的兩個任務，每顆模型各 20 次、由人類評分到哪個階段。數據照報：

- **放積木進碗**：Astra 完成 19/20（95%），Fable 5.1 是 8/20（40%）、Fable 5 是 1/20（5%）——Astra 完成率約為 Fable 5.1 的 2.4 倍，單次估算成本 0.94 美元（Fable 5.1 為 2.12 美元、Fable 5 為 2.69 美元），輸出 token 約 2.1k（對比 12.9k／19.2k）。
- **拼圖**：Astra 只完成 2/20，跟 Fable 5.1 的 2/20 相同，Fable 5 是 0/20。評測者註記 Astra「到達凹槽後，卡在 Fable 卡住的最後一步——同一格」。
- 成本：Astra 單次約 1.36 美元，仍是最便宜。

把兩張表讀在一起，那張「領先」的敘事就只成立在簡單任務上。放積木這種低精準度、少推理步的任務，Astra 幾乎全過、還便宜一大截；一旦換成需要精準對位的拼圖，Astra 的完成率掉回跟 Fable 5.1 相同、卡在同一個最終步驟——評測者自己點破它不是「超越」了難題，只是「更快地跑到同一個牆上」。限制條件要放大：每顆模型各 20 次是小樣本，成本按官方清單價估算、含人類評分環節，agent policy 統一所以比的是模型對操控的「指揮」，不是整支機械手臂系統的成敗。這則的看點是第三方的、開放碼方法、附完整 transcripts 與影片可復現——在「最強模型」的 P.R. 浪潮裡，一個肯把失敗率也列在表上的側寫。

- **論文：embedding 之間沒有成對資料也能互譯，並洩漏向量資料庫的密**：一篇 arXiv 論文提出第一種「無成對資料、無 encoder、無預設匹配」就能在不同模型的 embedding 向量空間之間翻譯的方法，宣稱跨架構、跨參數量都能維持高餘弦相似度。它更直白的後半段是安全意涵：攻擊者只要能拿到 embedding 向量，就有機會推斷底下文件的分類與屬性——向量資料庫的安全，不能只假設「向量看不懂」。論文標註日期為 5 月，是被爬蟲池翻出來的一則理論向材料。→ [arxiv.org](https://arxiv.org/abs/2505.12540)
